# 🧱 Data Modeling with dbt & Google BigQuery

## 📅 Duration
**June 2024**

## 📌 Project Overview
This project demonstrates how to set up and use **dbt (Data Build Tool)** in combination with **Google BigQuery** to build a scalable and testable data transformation pipeline. It includes the full setup, modeling, testing, documentation, and troubleshooting of a dbt-powered workflow on BigQuery.

## 🧰 Tools & Technologies
- **DBT (Data Build Tool)**
- **Google BigQuery**
- **SQL (CTEs, views, table materializations)**
- **Git** (for version control)

## ⚙️ Key Features

### 🔧 Setup and Integration
- Installed dbt locally and configured service account credentials.
- Connected dbt with BigQuery, resolving dataset ID and project config issues.

### 🧩 Data Modeling
- Built modular SQL models to transform raw BigQuery data.
- Used **Common Table Expressions (CTEs)** for complex data logic.
- Materialized models as both **tables** and **views** for performance optimization.

### ✅ Testing and Validation
- Added dbt tests for:
  - **Primary key constraints**
  - **Uniqueness**
  - **Non-null checks**
- Ensured data integrity and reliability across models.

### 📚 Documentation and Version Control
- Generated dbt documentation for models and schema.
- Used **Git** to version control model changes and maintain a clear change history.

### 🛠️ Troubleshooting
- Diagnosed and fixed common errors like:
  - Dataset ID mismatches
  - Service account permission issues
  - Model compilation errors

## 🚀 Outcome
- Created a fully functional dbt-BigQuery data pipeline.
- Modeled and tested data transformations with best practices in place.
- Gained hands-on experience in modern data engineering workflows.

## 📁 Project Structure

| Folder/File         | Description                                     |
|---------------------|-------------------------------------------------|
| `models/`           | Contains all dbt models written in SQL          |
| `dbt_project.yml`   | dbt configuration file                          |
| `profiles.yml`      | BigQuery credentials and connection setup       |
| `tests/`            | Custom tests for data validation                |
| `target/`           | Compiled models generated by dbt (ignored)      |
